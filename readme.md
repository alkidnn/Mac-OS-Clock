# MacOS Clock

Made by **notmangoytvr**

A minimal Rainmeter clock featuring the Apple iOS lock screen clock font with a subtle, slightly transparent look.

## Features
* **Apple iOS Lock Screen Clock Font** (already included in `@Resources`—no separate font download required)
* **Slightly transparent** styling (30% transparency)

## How to Download & Install
1. Make sure [Rainmeter](https://rainmeter.net) is installed on your PC.
2. Go to the **Releases** section on this repository and download the `.rmskin` file.
3. Once the download is finished, double-click the `.rmskin` file and click **Install**.
4. Open Rainmeter, find **MacOS clock**, and press **Load**.
